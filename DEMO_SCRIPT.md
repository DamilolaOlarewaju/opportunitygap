# OpportunityGap demo (about five minutes)

1. **Problem (30 seconds):** Students may avoid applications because they cannot
   relate role requirements to their existing experience. Our initial four-response
   survey is preliminary evidence, not proof of demand or representative research.
2. **Inputs (45 seconds):** Open the app on port 3000. Select Demo and load the
   synthetic sample. Point out the CV's explicit lack of testing experience and the
   internship's degree, experience and availability requirements.
3. **Comparison (60 seconds):** Analyse the sample. Inspect the role and CV excerpts.
   Explain that support is self-reported. Testing is an explicit gap; unstated
   professional experience is unknown. Studying toward a degree does not establish
   the completed credential, and a project cannot replace it.
4. **Learning → opportunity (60 seconds):** Inspect the tested task planner action.
   It links to R3 and builds on R1/R2. Show the concrete deliverable, test checklist
   and GitHub README evidence the student should capture. No repository was inspected.
5. **CV and download (45 seconds):** Compare the existing-experience rewrites with
   exact input excerpts. Show the separate future template labelled “use only after
   completion.” Download the text action plan and open it for offline reading.
6. **Limitations and Codex (60 seconds):** Demo is deterministic; real model calls
   remain unverified here. AI integration has server-only credentials and tested
   contract/error handling. Explain actual Codex contributions listed in README.
   No hiring score, invented achievements, automatic input storage or outcome claims.

## Fallback

If AI analysis fails, show the error and preserved text. Explicitly select Demo and
click Load sample inputs; do not describe the sample as analysis of the student's CV.
The demo does not need credentials or provider access once the app is running.
If starting the app fails, run the README's install/build/start commands. A downloaded
plan is an offline reading artifact, not evidence that the website works offline.

No video publication or final capstone submission is performed by this build.
